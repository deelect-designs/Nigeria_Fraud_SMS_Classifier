# Fraud SMS Classifier

## Overview

This project is a machine learning-powered web application that classifies SMS messages as either Spam (Fraudulent) or Ham (Safe). It uses Natural Language Processing (NLP) techniques and supervised learning algorithms to detect fraudulent SMS messages.

## Features

- Spam detection
- Confidence score
- TF-IDF vectorization
- Multiple machine learning models
- Interactive Flask web application
- Responsive user interface
- Deployment-ready architecture

## Technology Stack

- Python
- Flask
- Scikit-learn
- Pandas
- NLTK
- HTML
- CSS
- JavaScript
